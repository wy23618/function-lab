# 函数实验室

面向考研数学的本地函数实验台。输入后立即预览，用中文工具叠加比较原函数、变换后的函数和几何镜像关系。

## 启动

Windows 上双击项目根目录的 `启动函数实验室.cmd`。它启动已构建的本地版本并打开浏览器；本地服务只监听本机。需要停止时，在任务管理器中结束该服务的 Node.js 进程，进程编号记录在 `.runtime/server-5173.pid`。

开发模式：

```powershell
npm install
npm run dev
```

打开终端显示的本地地址。修改源代码后，可运行 `npm run build` 更新双击启动使用的版本。需要 Node.js 22 或更高版本。

## 在线访问

已部署到自有云服务器：<https://121.199.74.171/function-lab/>。应用由 Nginx 从静态文件提供，运行在 `/function-lab/` 路径下；原有 `/api/v1/` 路由保持不变。每位访问者的数据保存在自己的浏览器中，实验可通过导出/导入文件分享。

## 使用

- 在左侧输入 `x²`、`sin x`、`e^(πx)`、`ln(x)` 或 `1/(x-2)`；输入即预览，按 Enter 或 ＋ 保留。
- 数学键盘支持常数、括号、根号、绝对值、指数、三角函数和反三角函数。`e^πx` 兼容为 `e^(pi*x)`；显式 `e^π*x` 保持为 `e^π` 乘 `x`。复杂指数请加括号。
- 函数列表可编辑、隐藏、复制、锁定、改色、删除，以及只看某一条曲线；函数在本地浏览器自动保存。
- 函数 ⋮ 菜单中的「变换与分析」打开工具面板。「变换」支持五种常见对称、平移、伸缩、四种绝对值操作。参数实时预览，保留后生成独立函数，原图保留。
- 「分析」支持 `x>0`、`x≥0`、`-2≤x≤5`、区间格式的定义域；奇偶性、零点、交点、反函数、导函数、切线和法线。
- 「几何」可输入 `x=2`、`y=-2x+1` 或 `2x+3y-4=0`，反射函数和点击添加的观察点。
- 「历史」显示当前函数从原式到每一步变换的链。支持撤销/重做、Ctrl+K 搜索工具、滚轮缩放、拖动、复位、全屏及图像设置。
- 导出实验保存函数、观察点和视口。导入仅接受有效的实验 JSON，核心功能无需账户、网络或 API Key。

## 数学约定与范围

`ln(x)` 与 `log(x)` 均为自然对数；`log(x,10)` 表示常用对数，`log(x,2)` 表示以 2 为底。角度使用弧度。

完整平方函数关于 `y=x` 的镜像是关系 `x=y²`，不是 `√x`。限制为非负或非正分支后才能生成反函数。已知基函数及其线性变换使用完整定义域判断；无法可靠符号求解时提示限制，并提供独立的几何镜像操作。

零点、交点和切点斜率是数值结果，显示搜索区间或近似标记；有限采样不能证明任意复杂表达式的全局性质。自适应绘图对常见极点分段，按视口重新采样，并保留实数域与继承的定义域限制。极值、单调区间和值域的通用分析，以及渐近线自动识别属于规格允许的后续扩展。

## 验证与结构

```powershell
npm test
npm run lint
npm run build
```

`src/services` 保存解析、采样、变换、反函数、分析、几何和持久化服务；`src/components` 保存画布、列表和键盘；`src/types` 统一模型；`src/tests` 保存数学和回归验收。

浏览器验收脚本位于 `scripts`。开发服务启动后运行 `node scripts/browser-check.cjs` 和 `node scripts/advanced-browser-check.cjs`。脚本使用 Playwright；可设置 `NODE_PATH` 指向带有 Playwright 的环境，默认测试本机 Chrome。截图与测试报告统一记录在 `.runtime`（不纳入 Git），进度与验收覆盖见 `docs/DEVELOPMENT_STATE.md`、`docs/TASKS.md`、`docs/ACCEPTANCE.md`。


支持 `sinx`、`sin2t`、`sincosx`、`e^(Πt)` 等常见简写。自变量可用 `x`、`t`、`m`、`n` 等单个字母，例如 `u(t)=m*t+n`；多个字母时默认优先选 x、再选 t，也可在「变量与参数」中切换，其他字母默认值为 1，可用数字框或滑块调整。常量 e 和 pi 保留为数学常量。

复合函数支持嵌套表达式 `sin(t^2)`，也支持先添加 `u(t)=t^2`、`v(m)=sin(m)` 后输入 `u(v(t))`。命名引用保存添加时的定义、参数和定义域；修改或删除原条目不会破坏已添加的复合函数。自动生成的变换公式会整理冗余括号，并保留 π、e 等数学常量的写法。单字母相邻可隐式相乘，如 `mt`；存在歧义时用 `*` 和括号明确含义。反函数按当前参数值生成，复杂受限复合函数无法完整证明时提供对称关系并说明原因。


## 2026-10-13 界面重构

首页以快速画图为主：紧凑公式输入、可编辑的函数图层列表和大画布。函数变换/分析/几何/历史通过函数 ⋮ 菜单按需打开。桌面为左侧输入、右侧画布；手机竖屏为可拉拽分界的单页工作台；手机横屏为输入侧栏与画布并排。触屏点击输入框展开自带数学键盘，保存后收起。

常用键盘包含数字、x/t、幂、根号、括号、π/e、ln 和三角函数；字母页保留完整大小写字母与 x/t/m/n/a/b 快捷区。函数和符号页保留完整已有输入能力。括号/幂自动补齐，空括号成对删除，右括号可跳过已有闭合，跳出键进入括号外。实时公式预览使用上标与分式，明确复合指数范围。原有数学服务与已有保存数据沿用。

## 目录维护

源码与测试位于 `src/`，启动及验收脚本位于 `scripts/`，长期文档位于 `docs/`。`specification.txt` 为原始需求留档。

`node_modules/` 是运行依赖，通过 `npm ci` 恢复；`dist/` 是双击启动所需构建产物，通过 `npm run build` 重建。`.runtime/` 保存临时截图、日志、调试文件和发布产物，停止本地服务后可以清空。这些目录均不纳入 Git。

当前界面浏览器回归入口为 `npm run test:browser`；其余浏览器脚本保留早期专项验收场景，部分选择器对应旧界面。
