# 连通的函数工作台 · 2026-11-18

当前为本地实现与构建记录，未据此更新线上服务。工作台以「简约、功能完整」为原则：同一个函数输入，四个直接入口，图像与关键数值保持同屏，更多内容在「分析」中展开。

## 输入与切换

- 输入普通表达式、`y=f(x)`、命名函数、`x=2`、`x=ky+b`、`x=y^2`。后两类以 y 为自变量，不强行转换为单值 y 函数。
- 分数、平方、根号、sin、ln、π 可快捷插入；选中一段表达式后可整体包裹。分数模板会选中可替换位置。
- 「例题」提供普通函数和典型间断模型；「分段」用左右式与分界点生成条件表达式。也可输入 `x<0 ? -1 : 2` 或 `x==0 ? 7 : sin(x)/x`。
- 添加带参数函数后，输入区下方直接调整参数，研究图像同步更新。
- 输入有效草稿时可直接研究，不必先添加。点击已有函数时切换研究对象，同时保留未保存输入；再次点击输入框即可恢复草稿预览。
- 在画图、导数、积分、泰勒之间直接切换。手机竖屏入口在画布顶部，短横屏入口在应用顶部。

## 高阶导数

默认从 1 阶开始，支持 1–12 阶。用加减按钮逐阶切换，也可以直接输入目标阶数。「分析」里另有快速换阶滑块。默认显示原函数、上一阶与当前阶，避免同时堆满所有曲线。

当前 n 阶对应第 n−1 阶曲线的切线斜率。观察点拖动、数值输入（支持 `pi/2` 等常数）、滑块与播放动画同步更新切线和函数值。切换导数阶数时自动适应图像，仍可自行平移缩放。

「分析」中查看逐阶公式与当前点的值，按需开启所有低阶曲线。符号导数保留定义域、来源与逐阶可导条件；不可导或无法可靠检查的点不绘制假切线。符号系统不支持的表达式或过长的结果会提示限制。

## 积分与动态面积

蓝线为被积函数 f，绿线为 F(x)=C+∫ₐˣ f(t)dt。面积和积分函数共用同一个下限 a，不再另设第二个起点。连续点处，蓝色高度对应绿色切线斜率；F 的值对应累积有向面积加 C。

- 默认「变上限」，观察点就是面积上限；切换「定积分」后，a、b 固定，观察点可独立移动。
- 图中的 a、b 圆点可直接拖动；上下限支持 `pi/2`、`∞`、`-∞`。无穷区间的阴影只显示当前可见部分。
- 绿色、橙色阴影分别对应函数在轴上方、下方；上限小于下限时积分反号，阴影仍按函数正负着色。
- 「分析」中调整 C、输入已知奇点/分割点、查看分段结果和逐次截断。适应图像会同时考虑被积函数与数值积分函数。
- `x=g(y)` 使用 y 作为积分变量，面积相对纵轴展开，切线与观察点也交换坐标。

间断点分别处理：可去间断的孤立赋值不改变积分，F′ 取共同极限；跳跃点显示左右切线，不把某个分支的点值当作唯一导数；无穷与振荡情况保守判断。未受定义域限制的 `sin(1/x)` 有专用振荡尾部估计，可展示其积分函数在 0 的导数为 0；不把这个特例推广到其他振荡函数。

数值积分采用内部 Gaussian 节点、自适应细分、端点幂代换、无穷尾部几何分段。奇点两侧分别检验，不用对称抵消把柯西主值当作普通反常积分。`1/x` 跨越 0 不输出总值；`1/sqrt(abs(x))` 等可积奇点可观察稳定结果。

**数值稳定不等于收敛证明。** 间断分类与贴图均包含有限采样；高频振荡、极窄峰、未填写的奇点、极慢收敛可能超出计算范围。未确认收敛时隐藏总值。

## 泰勒展开

展开点 x₀、求值点 x 与阶数分别控制，支持 0–12 阶。可拖动原曲线上的 x₀ 圆点，也可输入展开点；图下滑块只移动观察点，阶数可在图上方直接改，也可以展开「分析」连续滑动换阶。

蓝线是原函数，橙线是当前多项式。浅绿带表示从展开点向两侧、当前视窗内采样误差不超过容差的连续范围。下方显示原值、多项式值与绝对误差。

「分析」提供容差、展开式与系数、当前观察点的 0–12 阶误差对照（符号系统能算到 12 阶时）和最多 30 个位置的同时求值。点击阶数可直接采用；多点支持 `-1, 0, pi/2, 2`。

阶数与非零项数不同。当前点满足容差不代表整段贴合；浅绿带也是采样估计，不是严格误差界或级数收敛区间。`ln(1+x)` 等函数增加阶数未必在整个定义域逼近。

## 操作与关联保存

按住画布拖动观察点；Shift 拖动或切换平移工具移动画布；滚轮和双指缩放。画布右上角的「⋯」提供缩放、适应图像和全屏。支持键盘切换研究标签与输入数值。

「保留曲线」将导数或泰勒多项式加入列表，并按来源身份关联。修改来源表达式、参数或依赖后自动重算；来源不满足计算条件时标记暂不可用并停止绘制，恢复条件后重新计算。删除来源后保留最后快照；关联随项目导入导出保存。直接编辑或变换结果会得到独立函数。

保留草稿的研究曲线时，会先一起保存来源。工作台端点、阶数、展开点、求值点、容差和多点输入保存在当前浏览器；视野沿用主画布。自动播放、分析面板和全部低阶曲线不会在刷新后自动打开。研究设置不属于项目 JSON；需随项目带走的结果请先保留曲线。
