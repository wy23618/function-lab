# 开发状态

日期：2026-10-12。阶段：五阶段及用户追加输入能力已完成并通过验收。

## 架构

React 19 + TypeScript + Vite 7，本地静态应用，mathjs 15 负责安全 AST、符号求导与已知数学结构。Canvas 绘制等比例坐标，视口变化触发自适应分段采样。数学计算独立于 UI。

统一模型 `FunctionDefinition`：表达式、颜色、可见性、锁定、定义域、父函数、完整变换链；几何关系保存源对象和反射直线，逆向投影视口角点确定原参数范围。`domainConstraints` 与 `differentiabilityChecks` 保留复合变换后的空隙、实数域和不可导点。

## 已完成

五阶段功能均已集成：安全输入/数学键盘、多函数与画布交互、变换实时预览/独立生成、历史/撤销重做、定义域与反函数、奇偶性/零点/交点、直线/点反射、导函数/切线/法线、命令面板、响应式布局、本地函数保存、实验导出导入、Windows 双击启动。

## 关键修复

- `πx`、`Πx`、`e^πx` 输入兼容，明确显式乘法与带括号指数的区别。
- 低幅极点和偶阶极点使用相对曲率与四分点递进采样，不使用固定绝对振幅门槛。
- 镜像关系不会误称为反函数；平方分支与三角函数分支按完整定义域证明；未知形式明确说明限制。
- 导数简化保留原实数域和孔洞；局部斜率检查收敛，拒绝尖点和垂直切线。
- 无效列表编辑不覆盖保存的有效表达式；无效导入中文报错。
- 小屏画布完整填满区域，超出初始调色板仍分配独立颜色。

## 范围

仅监听本机，无账户、数据库或付费依赖。零点、交点、斜率属于明确标注的数值结果；有限采样不作为任意表达式全局数学证明。通用值域、极值、单调区间、渐近线自动识别为规格明确允许的后续模块，模型接口可扩展。

实验最多 150 条曲线，表达式最多 4000 字符，镜像链最多 30 层；超出限制在提交前报错，不破坏保存数据。


追加能力：单字母自变量、可调参数、紧凑数学输入、命名与嵌套复合函数。bindings 保存引用快照并传递定义域；参数变化按不可变模型更新绘图缓存，导数的有效性检查同步参数值。62 项测试通过。
