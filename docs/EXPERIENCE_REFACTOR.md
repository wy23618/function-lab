# Function Lab 工作台体验重构 · 2026-10-20

## 产品与优先级

面向数学学习者的浏览器函数实验台。核心任务是输入表达式、观察图像、选择函数、调节变换或分析性质，然后与原函数对照。React/Canvas 负责交互与绘图，mathjs 和本地数学服务负责计算，Cloudflare 提供静态文件；没有数据库或远程计算 API。

按影响确定本次优先级：先保证图像与操作互不遮挡，再缩短高频工具路径，最后统一视觉、补齐保存与异常反馈。沿用原有数学引擎、函数数据格式、JSON 文件与发布流程。

## 审计与落地

| 发现的问题 | 实际改动 |
| --- | --- |
| 工具浮在图像上，展开后挡住曲线 | 改为画布下方独立区域，图像与工具分别布局和滚动 |
| 零点、求导等需要进入“更多”寻找 | 增加“分析”入口，更多工具按变换、求解和函数设置分组 |
| 列表以编辑、删除为主，操作入口隐藏 | 函数行提供变换与分析入口、定义域和锁定状态，支持键盘选择 |
| 独显函数后恢复其余曲线需要逐个操作 | 存在隐藏曲线时提供“显示全部” |
| 手机首屏几乎全部用于画布 | 默认调整画布比例，编辑区单独滚动，添加按钮并入输入行 |
| 手机横屏和数学键盘挤占图像 | 横屏保留左右布局，键盘使用左栏；竖屏键盘停靠底部 |
| 多轮追加的样式互相覆盖 | 重建颜色、间距与组件规则，按基础、工作台、工具、设备布局组织样式 |
| 搜索工具仅支持回车，缺少无结果提示 | 独立 CommandPalette，支持方向键、焦点约束与返回、空状态和可访问名称 |
| Esc 一次关闭所有工具 | 按弹层顺序逐层关闭，保留下方工作状态 |
| 刷新丢失观察点、辅助线和视野 | 新增独立工作台存储，校验坐标、范围、辅助线和记录数量，防抖写入并在离开页面时保存 |
| 缩放后分析仍固定搜索中心左右 8 单位 | 按画布实际宽度和缩放比例确定搜索区间 |
| 不可导切点会阻止整个导函数生成 | 将符号求导与切线有效性检查分开，仍保留不可导点排除逻辑 |
| TSX 公式测试存在但没有被运行 | 修正 Vitest 匹配范围，纳入已有公式显示测试 |

## 验证入口

`npm run check` 执行数学与持久化测试、ESLint、TypeScript 和生产构建。

`npm run test:browser` 执行原有图像与数学交互回归，以及新增工作台验收。新增覆盖 320×640、360×740、390×844、768×1024、1024×768、1366×768、1920×1080、667×375、844×390，检查工具不遮挡曲线、点击入口不受阻、键盘、分层 Escape、搜索、刷新恢复、切点不可导时求导及文件导入导出。旧脚本继续覆盖复合函数联动、删除来源、撤销、触控和手动横屏。

截图和测试导出文件放在 `.runtime/`，不提交个人实验数据。

## 验证边界

浏览器自动化基于 Windows Chrome 的窗口和触屏模拟，不能替代 iOS Safari、Android、真实软键盘及硬件旋转测试。数学分析继续遵循数值近似与受支持反函数分支的既有边界。构建仍有 mathjs 引起的大包提示，本次未更换依赖或数学框架。

本次只修改和验证本地版本，发布需用户体验确认后再执行。

## 本轮极简视觉调整

根据用户进一步提出的极简方向，去除主界面卡片包裹、Logo 色块、副标题、口号、示例标签、保存说明和画布标题。输入框内嵌添加/保存按钮；列表恢复为单行，低频操作集中在菜单。默认隐藏重复的画布公式目录，在设置提供开启入口。颜色主要用于函数曲线，控件采用灰阶，选中工具以细下划线表达。

桌面采用无外间距的侧栏与画布，手机采用画布、轻量分界和滚动编辑区；触控键盘与横屏布局沿用并继续验收。前文的快捷入口与行内说明改为按需显示，此处为当前视觉规范。

## 左栏交互专项

再次按用户反馈调整：公式点击改为查看，编辑使用独立铅笔入口；当前编辑目标独立于正在查看的曲线，切换查看与收起键盘均保留草稿。键盘开关与唯一添加/保存入口固定在输入框下方。取消恢复普通添加状态，原函数不变；清空全部函数移入设置。

列表独立滚动，键盘减少重复操作及重复字母。图像增加当前函数读数、曲线完整短公式与选中曲线强调，并为公式标签的幂和 π 替换增加回归测试，避免视觉简写改变数学含义。专项浏览器测试覆盖五种布局的选择、编辑、取消、保存和连续添加。

## 删除、复合与输入容错专项

恢复单行直接删除，加入就近撤销与聚焦行的 Delete 支持；彩色圆点切换显示，改色移入更多菜单，保持行宽。删除检查锁定状态，清理被删除函数的编辑状态，保留并可撤销已有复合依赖。

复合面板改为独立的内、外函数选择器，结果与交换按钮放在同一行，规则按需展开。已选来源被删除时显示空选项和明确提示，阻止保存无效预览。已保存结果仍使用原有依赖与冻结机制。

输入字符规范化与编辑器补全分层：数学引擎接受全角符号、大小写内置函数、函数幂、对数简写、变量隐式相乘和组合记号；只有编辑器会补齐缺失的末尾括号，核心解析器仍严格校验表达式。注册的自定义函数名称优先，保留既有名称与计算含义。原文与识别结果分别呈现，增加输入法组合状态保护，并拆开输入错误和工具错误。

新增数学与浏览器回归覆盖符号含义、顺序、定义域、删除/撤销引用、来源缺失、IME 确认及错误后即时重试。未增加依赖或服务器计算。
